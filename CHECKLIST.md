# Checklist antes de publicar tu observatorio

## Datos
- [ ] Cada cifra tiene fuente, enlace y periodo.
- [ ] La licencia de la fuente permite reutilizar (Ley 37/2007 para datos públicos españoles: citar fuente y fecha, no alterar, no sugerir patrocinio).
- [ ] No mezclas fuentes que miden cosas distintas en una misma serie.
- [ ] Has filtrado valores imposibles y cuentas cuántos descartas.
- [ ] Los totales cuadran y no hay territorios contados dos veces.
- [ ] Las cifras de los titulares coinciden con la fuente original.

## Automatización
- [ ] El script valida los datos y NO publica si algo falla (mejor datos de ayer que datos rotos).
- [ ] La web muestra la fecha de la última actualización.
- [ ] Hay aviso cuando la fuente publica un periodo nuevo o cambia el formato.

## Responsabilidad
- [ ] Sin datos personales de particulares: si una fuente publica nombres o DNI de personas físicas, anonimízalos.
- [ ] Lenguaje neutral: «indicador», «atípico», «merece revisión». Nunca acusaciones.
- [ ] Explicas la metodología y sus límites.
- [ ] Hay una vía para pedir rectificaciones y respondes.
- [ ] Si señalas a organismos o empresas concretas, un abogado ha revisado el aviso legal.

## Web
- [ ] Revisión visual en escritorio y móvil (ver prompts/03-revision-visual.md).
- [ ] Sin errores de consola ni desbordamiento horizontal.
- [ ] Funciona en modo oscuro y es legible.
